## Development

Build the patch bundle using Gradle:

```bash
./gradlew buildAndroid
```

The generated `.mpp` bundle should be available in:

```text
patches/build/libs/
```

For development guidance, see the
[Morphe documentation](https://github.com/MorpheApp/morphe-documentation).
